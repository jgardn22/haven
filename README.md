# HAVEN

Published copy of **H.A.V.E.N. - Health Agentic Value Enablement Network**, a planning aid for finding, selecting and modeling high-value healthcare AI agents.

**Live site:** https://jgardn22.github.io/haven/

- `index.html` - the HAVEN workbench (one self-contained file; selections are saved only in the visitor's browser)
- `demo.html` - side page with a link to the HAVEN demo video
- `version.json` - the build currently published

This site is refreshed automatically every Monday from the HAVEN team's latest build.
HAVEN is a planning aid, not an official Microsoft product, quote, or commitment.
